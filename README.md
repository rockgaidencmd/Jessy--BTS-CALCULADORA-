# 💜 Regla del Aspa — Para Jessy ARMY

Calculadora de diluciones IV usando el **Método de Aligación (Regla del Aspa)**.

## ✨ Características

- 💧 **Solución Salina** — Soletrol Na 20% / NaCl 17.7%
- 🍬 **Dextrosa** — 50% + 5%
- ⚗️ **Genérica** — cualquier concentración personalizada
- Cálculo automático de ampollas
- Pasos claros sin ambigüedad
- Tema BTS 💜 con música Dynamite

## 🚀 Cómo ejecutar localmente

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173)

## 📦 Cómo hacer build para producción

```bash
npm run build
```

La carpeta `dist/` contiene la app lista para subir a GitHub Pages.

## 🌐 Deploy en GitHub Pages

1. Haz push del proyecto a un repositorio de GitHub
2. Ve a **Settings → Pages**
3. En **Source** selecciona `GitHub Actions`
4. Crea el archivo `.github/workflows/deploy.yml` (incluido abajo)
5. ¡Listo! La app estará en `https://tuusuario.github.io/nombre-repo`
